Networking Cheat Sheet — Chapters 1–5

An Introduction to Computer Networks (Dordal, 2e) · one-page review of the key facts, numbers, and formulas.

1 · Overview of Networks

  • Layers: Physical → Link → Network (IP) → Transport → Application.
  • Forwarding table: destination → next hop (neighbor form) or interface (interface form). Use default route otherwise most-specific / longest-prefix match.
  • Routing builds tables (control plane); forwarding uses them per packet (data plane).
  • Path choice: hop count vs sum of link weights (cost) — pick lowest total cost.
  • Routing loop = cycle of next hops; either 2-node back-and-forth or a real topology cycle. TTL/hop limit ends it.
  • BDP = bandwidth × RTT (data needed "in flight").
  • Congestion = too much traffic on a bottleneck → queues, delay, loss.

2 · Ethernet Basics

  • CSMA/CD = Carrier Sense Multiple Access + Collision Detection (wired, half-duplex).
  • Min frame 64 B lets a collision return before send ends = 512 bit-times = slot time 51.2 µs @10 Mbps.
  • Binary exponential backoff: after k-th collision wait random {0 … 2^k−1} slots; cap k at 10; abort after 16.
  • Learning switch: record source MAC + arrival port; unknown destination → flood all ports except ingress; aging expires stale entries.
  • Broadcast MAC = FF:FF:FF:FF:FF:FF.
  • Loops fatal: no TTL → broadcast storm + duplicate frames.
  • Full duplex (switched point-to-point) → no collisions.

3 · Advanced Ethernet

  • Spanning Tree (STP): root = lowest bridge ID; each switch picks a root port (least cost to root; tie → lower neighbor ID); each segment elects a designated port; the rest blocked → loop-free tree; recompute on failure.
  • VLAN: logical LAN independent of wiring. Access port = 1 VLAN to a host; trunk = tagged multi-VLAN between switches via 802.1Q (4 B tag, 12-bit VID).
  • TRILL / SPB: link-state routing + encapsulation, use all links (multipath) vs STP blocking.
  • SDN / OpenFlow: centralized control plane; flow entry = match → action (forward / flood / drop / send-to-controller); multi-table pipelines.

4 · Wireless LANs

  • CSMA/CA (collision avoidance): can't reliably detect collisions at the receiver, so defer.
  • DIFS = long contention wait; SIFS = short gap reserved for ACK/priority replies (so ACKs win).
  • Hidden node: two stations reach the AP but not each other → collide at the AP. RTS/CTS fixes it — the AP's CTS (heard by the hidden station) silences it.
  • ACK after SIFS may skip listening: stations that heard the data still defer; hidden transmitters are usually too far to collide at the receiver.
  • WiMAX / LTE: base station schedules subscribers (no contention); subscribers need not hear one another.
  • Mobility guard: Δd = v·t → time shift Δd/c; guard ≈ 2·Δd/c (c ≈ 300 m/µs).
  • Two-ray ground: received power ∝ 1/r⁴.
  • WPA2: four-way handshake binds fresh nonces → defeats simple replay.

5 · Other LANs

  • VPN: private connectivity over a public net via tunneling / encapsulation; split tunneling sends only some traffic through it. The tunnel endpoint needs a route outside the tunnel.
  • Token Ring (802.5) / Token Bus: a token circulates; only the holder transmits → collision-free.
  • Virtual circuit: connection-oriented; setup then data; switches hold per-flow state and translate the VCI per link as (VCI_in, in-port) → (VCI_out, out-port). Sender's out-VCI on a link = receiver's in-VCI on that link.
  • vs datagram: no setup, no per-flow state, packets routed independently.
  • ATM: 53-byte cells (5 B header + 48 B payload); fixed size → predictable queuing/jitter.
  • AAL-5 XOR parity cell: 1 extra cell recovers any single lost cell; overhead ≈ 1/N; break-even vs retransmission at p ≈ 1/N² (N = 20 → 0.25%).
  • Carrier Ethernet: Ethernet service across a provider network via EVCs.

Must-memorize numbers & formulas

  • Min Ethernet frame 64 B; slot 51.2 µs @10 Mbps
  • Backoff {0…2^k−1}, cap 10, abort 16
  • Broadcast FF:FF:FF:FF:FF:FF
  • BDP = bandwidth × RTT
  • Two-ray power ∝ 1/r⁴
  • Wi-Fi slot 9 µs (802.11g), SIFS 10 µs, DIFS 28 µs
  • Contention loss = contention / (contention + transmit)
  • Guard ≈ 2·Δd/c; c ≈ 300 m/µs
  • ATM cell 53 B (5 + 48); XOR break-even p ≈ 1/N²
  • 10 Mbps ≈ 1 byte / 0.8 µs
