Networking Cheat Sheet — Chapters 1–5 (dense single-page edition)

An Introduction to Computer Networks (Dordal, 2e) · concepts, worked numbers, and mini-examples for fast comprehension.

1 · Overview of Networks

  • Layers + role: Physical (bits) → Link (frames, MAC) → Network/IP (global addressing, routing) → Transport (end-to-end) → Application.
  • Forwarding table row = (destination, next hop). Neighbor form names the neighbor; interface form names the port. Lookup picks the most-specific (longest-prefix) match; otherwise the default entry.
  • Routing builds tables (control plane) · forwarding uses them per packet (data plane).
example table      longest-prefix
dest    next       /10 200.64.0.0 → B
A       direct     /8  200.0.0.0  → A
B       S2         dest 200.64.1.1 → B (more
default S3                           specific wins)
  • Path metric: hops treat links as equal; weighted cost sums link weights and picks the cheapest path.
S1─1─S2─1─S3   via S2: 1+1 = 2  ✔
S1─5─S4─1─S3   via S4: 5+1 = 6  ✘
  • Routing loop = cycle of next hops; is either a 2-node back-and-forth or an actual topology cycle. TTL / hop limit ends circulation.
  • BDP = bandwidth × RTT = data "in flight" to keep a path full (e.g. 100 Mb/s × 50 ms = 5 Mb ≈ 625 KB).
  • Congestion = too much traffic on a shared bottleneck → queues, delay, loss.

2 · Ethernet Basics

  • CSMA/CD sequence: sense idle → transmit while watching → collision → send jam → back off → retry. (Wired, half-duplex.)
  • Min frame 64 B = 512 bit-times = slot time 51.2 µs @10 Mb/s, so a collision can return before the sender finishes; ties max span to the slot time.
  • Binary exponential backoff: after k-th collision wait random {0 … 2^k−1} slots; cap k=10; abort after 16.
collision → k=0,1,2,3 → tx in own slot
collision → k doubled (wider spread)
  • Learning switch: record source MAC + arrival port; unknown destination → flood all ports except ingress; aging expires stale entries.
A,B on S1 · C on S2 · S1──S2
1) A→B: S1 learns A; B unknown→flood
        (to B and S2); S2 learns A
2) B→A: S1 knows A → direct (no flood)
3) C→A: S2 knows A (via S1) → to S1 → A
  • Broadcast MAC FF:FF:FF:FF:FF:FF. Loops are fatal: no TTL → broadcast storm + duplicates.
  • Full duplex (switched, point-to-point) → no collisions.

3 · Advanced Ethernet

  • Spanning Tree (STP): ① root = lowest bridge ID; ② each non-root switch picks a root port = least-cost port to root (tie → lower neighbor ID); ③ each segment elects a designated port (best bridge to root); ④ all others blocked → loop-free tree; recompute on failure.
S1─S4─S6   root = S1
│  │  │    blocked: S5→S4 and S2→S6
S3─S5─S2   surviving tree keeps one path
  • VLAN: logical LAN independent of wiring. Access port = 1 VLAN to a host; trunk = many VLANs between switches.
802.1Q tag (4 B): [TPID 0x8100][PCP|DEI|VID(12b)]
  • TRILL / SPB: link-state routing + encapsulation → use all links (multipath), unlike STP which blocks them.
  • SDN / OpenFlow: centralized control plane; flow entry = match → action (forward / flood / drop / send-to-controller); tables can chain.

4 · Wireless LANs

  • CSMA/CA (avoidance): a station cannot reliably detect collisions at the receiver, so it defers and reserves instead. Wait DIFS (long) to contend; replies use SIFS (short) so ACKs win.
  • Hidden node: two stations reach the AP but not each other → they sense idle and collide at the AP.
A ~~ AP ~~ C      A,C hidden
no RTS/CTS: A and C tx together → collide at AP
RTS/CTS  : A→RTS; AP→CTS (heard by C)
           C defers; A sends; AP→ACK ✔
  • Wi-Fi timing (802.11g): slot 9 µs · SIFS 10 µs · DIFS 28 µs.
  • Contention loss: interval 64 slots → 64×9 = 576 µs; packet 151 µs → lost ≈ 576/(576+151) ≈ 79%.
  • WiMAX / LTE: base station schedules subscribers (no contention); subscribers need not hear one another.
  • Mobility guard: Δd = v·t → shift Δd/c; guard ≈ 2·Δd/c. (33 m/s × 60 s = 1980 m → 6.6 µs → guard 13.2 µs.)
  • Two-ray ground: direct + out-of-phase reflection → power ∝ 1/r⁴.
  • WPA2: four-way handshake binds fresh nonces → defeats simple replay.

5 · Other LANs

  • VPN: private connectivity over a public net via tunneling/encapsulation; split tunneling sends only some traffic through it.
[outer IP][tunnel hdr][inner IP][data]
The tunnel endpoint itself needs a route
OUTSIDE the tunnel (avoid a routing loop).
  • Token Ring (802.5) / Token Bus: a token circulates; only the holder transmits → collision-free.
  • Virtual circuit: connection-oriented; setup first; switches hold per-flow state and translate the VCI at each link.
A─S1─S2─B   VC A→S1→S2→D:
  │  │      S1 (1,A)→(2,S2)
C─S3─S4─D   S2 (2,S1)→(3,D)
VCI is per-link: sender's out = receiver's in.
  • vs datagram: no setup, no per-flow state; packets routed independently.
  • ATM: 53-byte cells (5 B header + 48 B payload); fixed size → predictable queuing/jitter.
  • AAL-5 XOR parity cell: 1 extra cell recovers any single lost cell; overhead ≈ 1/N; break-even vs retransmit at p ≈ 1/N² (N=20 → 21 cells vs 20+400p → p = 0.25%).
  • Carrier Ethernet: Ethernet service across a provider net via EVCs.
